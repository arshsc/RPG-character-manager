# Upgrade RPG Character Manager
***


This project is a tool for managing RPG characters. You can create characters, see their stats, and compare them using charts. It can also generate random characters and quests, and save or load characters from CSV files. It helps you organize and track your characters easily.

## How to use the Project
***
1. Make sure the CSV is valid
2. Run the program 
3. Use the nubmered main menu to choose an option and press enter
4. Exit the program by choosing the "Exit" option

## List of key features
***
- Create and customize RPG characters
- View character stats in tables
- Compare characters using charts
- Generate random characters and quests
- Save and load characters from CSV files
- Track character progression and builds
- Filter and sort characters by class, race, or stats
